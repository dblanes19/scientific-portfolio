Gestión de referencias bibliográficas con Zotero

Autor/a

Daniela Blanco

Introduction

Objetive

  • Create a basic Quarto template for documenting course exercises.

  • Create new pages from the template without modifying the original file.

  • Use Visual Mode to edit Quarto documents.

  • Add text, figures, and tables.

  • Add references generated with Zotero.

  • Render a Quarto page.

  • Integrate a new page into the scientific portfolio.

  • Publish changes using Git and GitHub Pages.

Metodology

Esta práctica se divide en cuatro partes:

Parte I: Crear la plantilla de las prácticas

Paso I: Abrir el proyecto del portafolio.

  • Abrir el proyecto Scientific-portpolio

  • Abrir GitHub simultaneamente

  • Desde el panel files en el proyecto Scientific-portfolio de RStudio comprobar que están los archivos:

    • _quarto.yml

    • index.qmd

    • about.qmd

    • portfolio.qmd o portafolio.qmd

    • carpeta images

*Todo esto debe crearse dentro del proyecto asociado a la página Web Scientific-portfolio.

Paso II: Crear nuevo documento Quarto

  • Ir a File > New File > Quarto Document

En la ventana que aparece:

  1. Seleccione Document.

  2. En Title, escriba:

Título de la práctica

  1. En Author, escriba su nombre.

  2. Seleccione HTML.

  3. Seleccione Visual como editor, si aparece esta opción.

  4. Presione Create.

Paso III: Guardar el archivo como plantilla

Seleccione:

File → Save As

Guarde el archivo con el nombre:

plantilla.qmd

El archivo debe quedar dentro de la carpeta principal del proyecto del sitio web.

* Utilice nombres de archivos sencillos, sin espacios, tildes ni caracteres especiales.

Paso IV: Trabajar en Visual Mode

Compruebe que se encuentra trabajando en Visual Mode.

Si fuera necesario, seleccione Visual en la parte superior del editor.

Visual Mode permite editar el documento de manera similar a Microsoft Word.

Paso V: Construir la Estructura de la Plantilla

Debajo del título del documento agregue las siguientes secciones utilizando Heading 2.

Aquí se introducen los apartados del documento, tales como:

  • Introduction

    • Breve descripción del tema de la práctica y su importancia.

  • Objetive

    • Indique el objetivo principal de la práctica.

  • Metodology

    • Describa brevemente las actividades realizadas y los métodos utilizados.

      No es necesario incluir todos los códigos de R utilizados durante el laboratorio.

  • Resultados

    • Presente los principales resultados obtenidos durante la práctica.

      Esta sección puede incluir:

      • texto;

      • figuras;

      • fotografías;

      • gráficos;

      • mapas;

      • cuadros.

  • Interpretations

    • Explique qué significan los resultados obtenidos.

      Considere preguntas como:

      • ¿Cuál fue el patrón más importante?

      • ¿Qué indican las figuras o cuadros?

      • ¿Cómo se relacionan los resultados con el objetivo de la práctica?

  • Conclusions

    • Resuma brevemente las principales conclusiones o aprendizajes de la práctica.

  • Bibliography

    • Resuma brevemente las principales conclusiones o aprendizajes de la práctica.

Paso VI: Guardar Plantilla

Guarde los cambios:

Ctrl + S

Al finalizar debe existir el archivo:

plantilla.qmd

Importante: plantilla.qmd será nuestro archivo original. De ahora en adelante no escribiremos directamente sobre esta plantilla. Para cada nueva práctica crearemos una copia.

Parte II: Crear una práctica a partir de la Plantilla

Ahora utilizaremos plantilla.qmd para crear la página correspondiente a la práctica de Zotero realizada la semana anterior.

  1. Abra plantilla.qmd.

  2. Seleccione File → Save As.

  3. Guarde la copia con el nombre:

    zotero.qmd

  4. Compruebe que está trabajando en Visual Mode.

  5. Cambie el título por:

    Gestión de referencias bibliográficas con Zotero

  6. Complete brevemente las secciones de la plantilla utilizando el trabajo realizado durante la práctica anterior.

    Importante: no modifique plantilla.qmd. Esta se conservará para crear las próximas prácticas.

Insertar figuras

Se incorpora una figura sencilla para prácticar la inserción de imágenes en Quarto.

  1. Abra Zotero y seleccione la colección creada durante la práctica anterior.

  2. Tome una captura de pantalla donde se observe la colección y algunas de las referencias incorporadas.

  3. Guarde la imagen dentro de la carpeta images del proyecto del sitio web con el nombre:

    zotero_biblioteca.png

  4. Regrese a zotero.qmd y coloque el cursor en la sección Resultados.

  5. En Visual Mode, seleccione Insert → Figure.

  6. Seleccione zotero_biblioteca.png.

  7. Agregue como pie de figura:

    Ejemplo de una colección de referencias bibliográficas organizada en Zotero.

Compruebe que la figura aparece correctamente en el documento.

Insertar cuadros

En la sección Resultados, debajo de la figura, inserte un cuadro para resumir las formas de incorporar referencias utilizadas durante la práctica.

  1. En Visual Mode, seleccione Insert → Table.

  2. Cree un cuadro de 2 columnas y 5 filas.

  3. Complete el cuadro de la siguiente manera:

Método ¿Cuándo utilizarlo?
DOI Cuando la publicación tiene un DOI conocido
Archivo RIS Cuando la revista o base de datos permite exportar la referencia
Zotero Connector Para capturar referencias directamente desde el navegador
Entrada manual Cuando la información no puede importarse automáticamente

  1. Agregue como título:

    Métodos utilizados para incorporar referencias bibliográficas a Zotero.

Parte III: Incorporar las referencias de Zotero.

Ahora utilizaremos las referencias trabajadas durante la práctica anterior para insertar citas en zotero.qmd.

Exportar referencias

  1. Abra Zotero.

  2. Seleccione la colección utilizada durante la práctica.

  3. Haga clic derecho sobre la colección y seleccione Export Collection.

  4. Seleccione el formato BibTeX.

  5. Guarde el archivo dentro del proyecto del sitio web con el nombre:

    referencias.bib

  6. Regrese a RStudio y compruebe en el panel Files que aparece el archivo:

    referencias.bib

    *No continuar hasta comprobar que referencias.bib aparece en el panel Files.

Conectar Referencias con Zotero.qmd

Una vez que referencias.bib existe dentro del proyecto:

  1. Abra zotero.qmd.

  2. Cambie momentáneamente de Visual a Source.

  3. Localice el encabezado YAML que aparece al inicio del documento.

  4. Agregue la siguiente línea antes de format:

bibliography: referencias.bib

Ejemplo:

  1. Guarde el archivo.

  2. Regrese a Visual Mode.

    *Esta modificación se realiza en zotero.qmd, no en plantilla.qmd.

Insertar Citas

  1. Coloque el cursor en el texto donde desea insertar una referencia.

  2. En Visual Mode, seleccione Insert → Citation.

  3. Busque la referencia correspondiente.

  4. Selecciónela e inserte la cita.

Inserte al menos una referencia utilizada durante la práctica.

Presione Render y compruebe que la cita y la bibliografía aparecen correctamente.

Parte IV: Integrar la Práctica al Portafolio

Ahora conectaremos zotero.qmd con el cajón que ya existe en el sitio web.

  1. Abra portafolio.qmd.

  2. Localice el cajón:

    Gestión de referencias bibliográficas con Zotero

  3. Elimine el texto Disponible próximamente.

  4. Agregue una descripción breve de la práctica.

  5. Escriba:

    Ver práctica →

  6. Seleccione Ver práctica → y utilice la herramienta para insertar un enlace.

  7. Enlace el texto con:

    zotero.qmd

  8. Elimine el cajón Próximas prácticas, ya que a partir de ahora las prácticas reales se irán incorporando al portafolio.

Parte V: Actualizar y Publicar el sitio

  1. Guarde todos los cambios.

  2. Seleccione Render Website.

  3. Compruebe que el cajón de Zotero aparece correctamente.

  4. Compruebe que Ver práctica → abre zotero.qmd.

Si todo funciona:

  1. Abra la pestaña Git de RStudio.

  2. Marque los archivos nuevos o modificados.

  3. Seleccione Commit.

  4. Utilice un mensaje como:

    Agregar práctica de Zotero

  5. Presione Commit.

  6. Presione Push.

  7. Abra el sitio web publicado y compruebe que la práctica funciona correctamente.

Para las próximas prácticas

De ahora en adelante utilizaremos siempre el mismo procedimiento:

plantilla.qmd → Save As → completar práctica → Render → agregar al portafolio → Render Website → Commit → Push

El proyecto de R del curso se utilizará para trabajar con datos, códigos y análisis. El portafolio científico se utilizará para presentar y comunicar los métodos, resultados, figuras, cuadros, interpretaciones y conclusiones más importantes.
